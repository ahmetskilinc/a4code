# Use a4code as your default browser

On macOS, you can set the a4code desktop app as your default web browser so links from other apps and local HTML files open directly in a4code.

## Enable

Choose **a4code** in **System Settings → Desktop & Dock → Default web browser** (switch back there anytime).

## How links open

- If the active thread has its browser panel open, the link opens as a new tab there; otherwise a4code opens a new no-project thread with the browser panel maximized so you can ask an agent about the page right away.
- Pull request links for connected projects open in the PR view (when **Open pull requests in a4code** is enabled).
- [Prompt links](./prompt-links.md) open a draft in the desktop app.
