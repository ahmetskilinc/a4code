# Replace a desktop build

Finish active agent turns, quit the app, then install your replacement desktop build using the same data home. A remote host keeps its own executable. Replace its standalone CLI separately and restart its service when you are ready. [Build and installation](./install.md) · [Background service](./background-service.md)

## Continue threads after restarts

**Settings → Maintenance → Continue threads after restarts** controls whether eligible interrupted threads resume after the environment comes back. Review active threads before restarting a machine.
